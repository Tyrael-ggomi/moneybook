# 머니북 모바일 v0.6.4

현재 사용 중인 모바일 Moneybook 테스트 버전입니다.

## v0.6.4 변경사항
- 카드 순서 설정: ↑ / ↓
- 카테고리 순서 설정: ↑ / ↓
- 자동분류 규칙을 카테고리 순서와 동일한 순서로 표시
- Excel / Google Sheets 붙여넣기에서 `할부(2/2)`, `할부(3/6)`, `할부(12개월/3회차)` 등의 할부 표기 인식
- Sheets 가져오기 미리보기에서 일시불 / 할부 개월 수 표시
- 자동분류되지 않은 Sheets 항목은 기본 카테고리를 선택하지 않고 `미정`으로 등록
- `미정` 항목도 지출내역에서 검색/필터 및 수정 가능
- 모바일 날짜/시간 입력칸의 폭을 화면 안에 맞도록 보완

## 기존 주요 기능
- 지출 입력/수정/삭제/검색/필터
- 지출 날짜 + 시간 저장 및 날짜/시간순 정렬
- 카드별 결제일 + 이용기간 설정
- 3개월 결산
- 카드/카테고리/자동분류 설정
- Excel / Google Sheets 복붙 import
- 중복 의심 내역 미리보기
- 메모 추가/수정/완료/미완료/삭제

## 실행
```
python app.py
```

아이폰 테스트 시 PC와 같은 Wi-Fi에서 PC의 IPv4 주소로 접속합니다.
예: `http://192.168.0.15:8765`
